# Project Images

Drop your real renderings into THIS folder using the exact filenames below. The site will pick them up automatically — no code changes needed.

## Filenames the site is looking for

| Filename                     | What it shows                                  | Recommended size      |
|------------------------------|------------------------------------------------|-----------------------|
| `commercial-midrise.jpg`     | Hero project tile (large) — commercial mid-rise| 1600×1000 px, < 350 KB|
| `villa.jpg`                  | Modern villa tile                              | 1200×900 px, < 250 KB |
| `apartment.jpg`              | Apartment building tile                        | 1200×900 px, < 250 KB |

## Optimizing before upload

Use [squoosh.app](https://squoosh.app) (free, in-browser) to compress to WebP or JPEG quality ~78. Smaller files = faster site = better SEO.

## Adding more projects later

Edit `/index.html` and copy one of the existing `<div class="project ...">` blocks. Update the image filename, alt text (mention the location for SEO), and overlay title.
